A one-line roast of the wireless earbuds I use every day: they drop out mid-sentence so often my phone calls have better plot twists than my TV shows. The program writes that single line (109 characters) to `entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/roast-out python3 main.py
```
